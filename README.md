# CryptoPoker ♠️♥️♦️♣️

Project developed for my Cryptocurrencies and Blockchain Technologies module. Project is a poker system built using Ethereum Smart Contracts, developed using Solidity with the Remix IDE. Project is a functional prototype of a heads-up poker system, however, is lacking the cryptography necessary for deployment. Namely, the lack of privacy for a player's hole cards. This problem is referred to as the 'Mental Poker' problem and whilst solutions do exist they are often expensive. The most promising of these are zero-knowledge proofs, which could be implemented into this system for a fully functional decentralised poker game.
